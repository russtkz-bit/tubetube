# tubetube

Кроссплатформенная (Windows / Linux) программа для скачивания субтитров
с видео и плейлистов YouTube. Работает на Python + [yt-dlp](https://github.com/yt-dlp/yt-dlp),
сама видео не скачивает — только субтитры (обычные, авторские, и/или
автоматически сгенерированные), с конвертацией в `.srt`, `.vtt` или обычный
текст `.txt`. Для конвертации ffmpeg не требуется.

Есть два интерфейса:
- **графический (GUI)** — окно с полями и кнопками, можно собрать в один
  `.exe` (Windows) или обычный исполняемый файл (Linux/macOS);
- **командная строка (CLI)** — для скриптов и автоматизации.

## Установка

Нужен Python 3.8+.

### Linux / macOS

```bash
git clone <repo> tubetube
cd tubetube
./run.sh --help
```

При первом запуске `run.sh` сам создаст виртуальное окружение `.venv`
и поставит зависимости.

Либо вручную:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m tubetube.cli --help
```

Также можно установить как консольную команду:

```bash
pip install -e .
tubetube --help
```

### Windows

```bat
git clone <repo> tubetube
cd tubetube
run.bat --help
```

При первом запуске `run.bat` сам создаст виртуальное окружение `.venv`
и поставит зависимости (нужен установленный Python с добавлением в PATH).

Либо вручную (PowerShell/cmd):

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m tubetube.cli --help
```

## Графический интерфейс (GUI)

Самый простой способ для обычного пользователя — окно с полем для
ссылки, выбором языков, типа и формата субтитров, кнопками
«Показать доступные языки» и «Скачать субтитры», и логом хода работы.

В окне также есть кнопка **«Обновить yt-dlp»** — подтягивает последнюю
версию библиотеки yt-dlp с PyPI (`pip install --upgrade yt-dlp`). Это
важно: YouTube периодически меняет сайт, из-за чего старая версия
yt-dlp перестаёт скачивать субтитры, а разработчики yt-dlp обычно
быстро выпускают исправление — эта кнопка его подтягивает. Текущая
версия yt-dlp видна рядом с кнопками. После обновления программу нужно
перезапустить.

> В собранном `.exe` кнопка обновления не может обновить саму себя —
> внутри однофайлового exe нет pip и отдельного Python. Она покажет
> понятное сообщение об этом. Чтобы получить свежий yt-dlp в exe,
> обновите зависимость в исходниках и пересоберите файл через
> `build.bat`/`build.sh`, либо запускайте tubetube из исходников
> (`run-gui.bat`/`run-gui.sh`) — там обновление работает прямо из GUI.

### Запуск без сборки

```bash
# Linux/macOS
./run-gui.sh
```

```bat
:: Windows
run-gui.bat
```

Скрипты сами создадут виртуальное окружение и поставят зависимости при
первом запуске.

### Сборка в один .exe / исполняемый файл

Приложение можно собрать в один файл с помощью [PyInstaller](https://pyinstaller.org/),
чтобы запускать без установленного Python.

**Windows** (запускать на самой Windows — PyInstaller не кросс-компилирует):

```bat
build.bat
```

После сборки готовый файл будет здесь: `dist\TubeTube.exe`. Его можно
скопировать куда угодно и запускать двойным щелчком — Python и
зависимости пользователю ставить не нужно.

**Linux/macOS**:

```bash
./build.sh
```

Результат: `dist/TubeTube` — обычный исполняемый файл без расширения.

> На Windows для сборки нужен Python, установленный с опцией
> "tcl/tk and IDLE" (стандартный установщик с python.org включает её по
> умолчанию) — она нужна для графического интерфейса (Tkinter).
> На Linux, если venv ругается на отсутствие модуля `tkinter`, поставьте
> системный пакет `python3-tk` (Debian/Ubuntu: `sudo apt install python3-tk`).

## Использование (командная строка)

Скачать субтитры одного видео (по умолчанию — русские и английские,
и авторские, и автоматические, формат `.srt`):

```bash
tubetube "https://www.youtube.com/watch?v=XXXXXXXXXXX"
```

Скачать субтитры для целого плейлиста (ссылка на плейлист определяется
автоматически, файлы раскладываются по папке с названием плейлиста):

```bash
tubetube "https://www.youtube.com/playlist?list=XXXXXXXXXXXXXXXXX"
```

Посмотреть, какие языки субтитров вообще есть у видео:

```bash
tubetube --list-langs "https://www.youtube.com/watch?v=XXXXXXXXXXX"
```

Скачать субтитры на всех доступных языках в виде простого текста
(без таймкодов), только автоматические:

```bash
tubetube -l all -t auto -f txt "https://www.youtube.com/watch?v=XXXXXXXXXXX"
```

### Параметры

| Флаг | Описание | По умолчанию |
| --- | --- | --- |
| `-l`, `--langs` | Языки через запятую (`ru,en`) или `all` | `ru,en` |
| `-t`, `--type` | `manual` (авторские), `auto` (автоматические), `both` (оба) | `both` |
| `-f`, `--format` | `srt`, `vtt` или `txt` | `srt` |
| `-o`, `--output` | Папка для сохранения | `./subtitles` |
| `--keep-vtt` | Не удалять промежуточный `.vtt` при конвертации | выкл. |
| `--list-langs` | Только показать доступные языки и выйти | — |
| `-v`, `--verbose` | Подробный вывод yt-dlp | выкл. |
| `--gui` | Запустить графический интерфейс вместо CLI (`tubetube --gui`) | — |

## Как это работает

- Ссылка на видео или плейлист передаётся в `yt-dlp`, который сам
  определяет, что это (одно видео или плейлист), и скачивает только
  файлы субтитров (`skip_download=True`, видео не загружается).
- YouTube отдаёт субтитры в формате WebVTT — программа скачивает именно
  его, а затем конвертирует в `.srt` или чистый `.txt` собственным кодом
  (`tubetube/converter.py`), без внешних зависимостей вроде ffmpeg.
- При конвертации в `.txt` автоматически убираются дублирующиеся строки,
  характерные для «наезжающих» автоматических субтитров YouTube.
