# tubetube

Кроссплатформенная (Windows / Linux) программа для скачивания субтитров
с видео и плейлистов YouTube. Работает на Python + [yt-dlp](https://github.com/yt-dlp/yt-dlp),
сама видео не скачивает — только субтитры (обычные, авторские, и/или
автоматически сгенерированные), с конвертацией в `.srt`, `.vtt` или обычный
текст `.txt`. Для конвертации ffmpeg не требуется.

Есть два интерфейса:
- **графический (GUI)** — окно с полями и кнопками, можно собрать в один
  `.exe` (Windows) или обычный исполняемый файл (Linux/macOS);
- **командная строка (CLI)** — для скриптов и автоматизации.

## Установка

Нужен Python 3.8+.

### Linux / macOS

```bash
git clone <repo> tubetube
cd tubetube
./run.sh --help
```

При первом запуске `run.sh` сам создаст виртуальное окружение `.venv`
и поставит зависимости.

Либо вручную:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m tubetube.cli --help
```

Также можно установить как консольную команду:

```bash
pip install -e .
tubetube --help
```

### Windows

```bat
git clone <repo> tubetube
cd tubetube
run.bat --help
```

При первом запуске `run.bat` сам создаст виртуальное окружение `.venv`
и поставит зависимости (нужен установленный Python с добавлением в PATH).

Либо вручную (PowerShell/cmd):

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m tubetube.cli --help
```

## Графический интерфейс (GUI)

Самый простой способ для обычного пользователя — окно с полем для
ссылки, выбором языков, типа и формата субтитров, кнопками
«Показать доступные языки» и «Скачать субтитры», и логом хода работы.

Буфер обмена работает в обе стороны:
- **Вставка ссылки**: кнопка **«Вставить»** рядом с полем ссылки читает
  URL из буфера обмена и сразу подставляет его в поле (обычный Ctrl+V в
  поле тоже работает).
- **Копирование результата**: после скачивания кнопка **«Копировать
  пути»** копирует список путей ко всем сохранённым файлам субтитров в
  буфер обмена — удобно, чтобы сразу вставить их куда-то ещё.
- Правый клик по любому текстовому полю или по логу открывает меню
  «Вырезать / Копировать / Вставить / Выделить всё» (для лога — только
  копирование, он доступен лишь для чтения).

Обе эти операции (проверка языков и скачивание субтитров) можно
прервать кнопкой **«Отмена»** — она становится активной, пока идёт одна
из них. Отмена кооперативная: для плейлиста она останавливает процесс
между видео (не обрывает текущую сетевую операцию мгновенно), для
одного видео — сразу после того, как текущий шаг (получение метаданных
или запись файла) завершится. Уже скачанные к моменту отмены файлы
остаются на диске — в логе будет видно, сколько успело скачаться.

Поле **«Фильтр по названию видео (regex)»** позволяет скачивать
субтитры только из части плейлиста — например, только один раздел
курса (Домен 1.0 и т.п.), если он размечен в названиях видео.
Кнопка **«Предпросмотр»** рядом с полем показывает список всех видео
плейлиста в логе с отметкой `[+]`/`[ ]`, какие из них подходят под
текущий фильтр, и сколько всего совпало — так паттерн можно подобрать
и проверить до того, как что-то скачается. Пустое поле фильтра —
скачиваются субтитры всех видео плейлиста, как раньше.

В окне также есть кнопка **«Обновить yt-dlp»** — подтягивает последнюю
версию библиотеки yt-dlp с PyPI (`pip install --upgrade yt-dlp`). Это
важно: YouTube периодически меняет сайт, из-за чего старая версия
yt-dlp перестаёт скачивать субтитры, а разработчики yt-dlp обычно
быстро выпускают исправление — эта кнопка его подтягивает. Текущая
версия yt-dlp видна рядом с кнопками. После обновления программу нужно
перезапустить.

> В собранном `.exe` кнопка обновления не может обновить саму себя —
> внутри однофайлового exe нет pip и отдельного Python. Она покажет
> понятное сообщение об этом. Чтобы получить свежий yt-dlp в exe,
> обновите зависимость в исходниках и пересоберите файл через
> `build.bat`/`build.sh`, либо запускайте tubetube из исходников
> (`run-gui.bat`/`run-gui.sh`) — там обновление работает прямо из GUI.

Ещё одна кнопка — **«Обновить tubetube (git pull)»** — подтягивает
последние изменения кода самой программы из git-репозитория
(`git pull --ff-only`, без слияний, чтобы случайно не создать
конфликт или не потерять локальные правки). Активна только если
программа запущена из git-репозитория (папка с `.git`) — то есть при
запуске из исходников (`run-gui.sh`/`run-gui.bat`). В собранном `.exe`
кнопка неактивна: там нет ни исходников, ни git, обновлять там нечего —
если нужна новая версия tubetube, пересоберите `.exe` заново. После
`git pull` программу тоже нужно перезапустить.

### Запуск без сборки

```bash
# Linux/macOS
./run-gui.sh
```

```bat
:: Windows
run-gui.bat
```

Скрипты сами создадут виртуальное окружение и поставят/обновят
зависимости — это происходит при каждом запуске (быстро, если всё уже
стоит), чтобы окружение само чинилось, если предыдущая установка не
завершилась. На Windows `run-gui.bat` держит открытым окно консоли,
пока работает GUI, — специально, чтобы в случае ошибки на запуске
(например, Python установлен без Tcl/Tk) сообщение было видно, а не
просто "ничего не произошло".

### Сборка в один .exe / исполняемый файл

Приложение можно собрать в один файл с помощью [PyInstaller](https://pyinstaller.org/),
чтобы запускать без установленного Python.

**Windows** (запускать на самой Windows — PyInstaller не кросс-компилирует):

```bat
build.bat
```

После сборки готовый файл будет здесь: `dist\TubeTube.exe`. Его можно
скопировать куда угодно и запускать двойным щелчком — Python и
зависимости пользователю ставить не нужно.

**Linux/macOS**:

```bash
./build.sh
```

Результат: `dist/TubeTube` — обычный исполняемый файл без расширения.

> На Windows для сборки нужен Python, установленный с опцией
> "tcl/tk and IDLE" (стандартный установщик с python.org включает её по
> умолчанию) — она нужна для графического интерфейса (Tkinter).
> На Linux, если venv ругается на отсутствие модуля `tkinter`, поставьте
> системный пакет `python3-tk` (Debian/Ubuntu: `sudo apt install python3-tk`).

## Использование (командная строка)

Скачать субтитры одного видео (по умолчанию — русские и английские,
и авторские, и автоматические, формат `.srt`):

```bash
tubetube "https://www.youtube.com/watch?v=XXXXXXXXXXX"
```

Скачать субтитры для целого плейлиста (ссылка на плейлист определяется
автоматически, файлы раскладываются по папке с названием плейлиста):

```bash
tubetube "https://www.youtube.com/playlist?list=XXXXXXXXXXXXXXXXX"
```

Посмотреть, какие языки субтитров вообще есть у видео:

```bash
tubetube --list-langs "https://www.youtube.com/watch?v=XXXXXXXXXXX"
```

Скачать субтитры на всех доступных языках в виде простого текста
(без таймкодов), только автоматические:

```bash
tubetube -l all -t auto -f txt "https://www.youtube.com/watch?v=XXXXXXXXXXX"
```

Скачать субтитры только из определённого раздела плейлиста — например,
курс подготовки к Security+ размечен по доменам в названиях видео
("1.1 Compare Security Controls", "1.2 ...", "2.1 Common Threat
Actors" и т.д.), и нужен только Домен 1.0:

```bash
# Сначала подобрать паттерн: посмотреть список видео и что под него попадёт
tubetube --list-titles --title-filter '^1\.' "https://www.youtube.com/playlist?list=XXXXXXXXXXXXXXXXX"

# Когда паттерн подобран — скачать субтитры только для этих видео
tubetube --title-filter '^1\.' "https://www.youtube.com/playlist?list=XXXXXXXXXXXXXXXXX"
```

### Параметры

| Флаг | Описание | По умолчанию |
| --- | --- | --- |
| `-l`, `--langs` | Языки через запятую (`ru,en`) или `all` | `ru,en` |
| `-t`, `--type` | `manual` (авторские), `auto` (автоматические), `both` (оба) | `both` |
| `-f`, `--format` | `srt`, `vtt` или `txt` | `srt` |
| `-o`, `--output` | Папка для сохранения | `./subtitles` |
| `-T`, `--title-filter` | Regex по названию видео — скачивать только подходящие под него видео плейлиста | — |
| `--list-titles` | Показать список видео плейлиста (с отметкой [+]/[ ] под `--title-filter`, если задан) и выйти | — |
| `--keep-vtt` | Не удалять промежуточный `.vtt` при конвертации | выкл. |
| `--list-langs` | Только показать доступные языки и выйти | — |
| `-v`, `--verbose` | Подробный вывод yt-dlp | выкл. |
| `--gui` | Запустить графический интерфейс вместо CLI (`tubetube --gui`) | — |

## Как это работает

- Ссылка на видео или плейлист передаётся в `yt-dlp`, который сам
  определяет, что это (одно видео или плейлист), и скачивает только
  файлы субтитров (`skip_download=True`, видео не загружается).
- YouTube отдаёт субтитры в формате WebVTT — программа скачивает именно
  его, а затем конвертирует в `.srt` или чистый `.txt` собственным кодом
  (`tubetube/converter.py`), без внешних зависимостей вроде ffmpeg.
- При конвертации в `.txt` автоматически убираются дублирующиеся строки,
  характерные для «наезжающих» автоматических субтитров YouTube.

## Если субтитры не находятся, хотя они точно есть

YouTube в последнее время требует т.н. **PO Token** (проверку "не бот
ли это") для части операций, в том числе иногда для отдачи списка
субтитров. Обычно `yt-dlp` решает эту проверку через JS-рантайм (например,
[Deno](https://deno.com/)) — без него он использует упрощённый набор
клиентов, и для некоторых видео список субтитров может оказаться пустым,
хотя на самом деле они есть (в логе это выглядит как "There are no
subtitles for the requested languages", часто вместе с предупреждением
про "No supported JavaScript runtime").

tubetube уже старается компенсировать это — принудительно добавляет
клиент `web` в запрос к YouTube (он не всегда требует JS для самих
субтитров). Если после этого субтитры всё равно не находятся:

1. Включите галочку **«Подробный лог»** в GUI (или флаг `-v`/`--verbose`
   в CLI) и повторите попытку — в логе появится точная причина от
   yt-dlp (обычно строка про "PO Token").
2. Если причина подтвердилась — установите JS-рантайм по инструкции
   yt-dlp: https://github.com/yt-dlp/yt-dlp/wiki/EJS (например, Deno:
   `winget install DenoLand.Deno` на Windows или `curl -fsSL
   https://deno.land/install.sh | sh` на Linux/macOS). После установки
   `yt-dlp`/tubetube подхватят его автоматически.
3. Обновите yt-dlp кнопкой «Обновить yt-dlp» в GUI (или `pip install
   --upgrade yt-dlp`) — YouTube меняет требования часто, и новая версия
   может уже уметь работать без JS-рантайма для конкретно вашего случая.
